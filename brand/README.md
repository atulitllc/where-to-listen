# Where to Listen — locked mark

Option A: a microphone with three sound rings that shift from purple on the left to mint on the right. Original flat geometry. Not a podcast-app logo.

## Files

- `mark.svg` — icon, transparent background, viewBox `0 0 96 80`
- `lockup.svg` — horizontal mark + wordmark, transparent background

## Color

| Role | Hex | Use |
| --- | --- | --- |
| Wave start | `#7C5CFC` | Left edge of the rings |
| Wave mid | `#A78BFA` | Toward the microphone |
| Wave end | `#5EEAD4` → `#2DD4BF` | Right edge of the rings |
| Capsule top | `#DDD6FE` | Microphone highlight |
| Capsule | `#A78BFA` → `#7C3AED` | Microphone body |
| Cradle | `#A78BFA` | Yoke and stem |
| Foot | `#C4B5FD` | Base bar |
| Words | `#8B6CF6` | “findthis” |
| Accent | `#2DD4BF` | “podcast” |
| Night ground (recommended) | `#12141A` | Preview only; SVGs are transparent |

Outer rings step down in opacity (0.95 / 0.62 / 0.34) so the microphone stays the mark.

Wordmark is Outfit, the site’s text face. Purple and mint both read on the light shelf and the dark shelf.

Favicon is this mark on a `#14121C` squircle.
